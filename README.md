Hangman Game

Overview

This project is a Python-based implementation of the classic Hangman Game, developed as part of an internship task provided by CodeAlpha.The game allows users to guess a hidden word letter by letter while tracking incorrect attempts.

Features

Interactive gameplay
Random word selection
Input validation
Limited guessing attempts
Win/Lose conditions
Command-line interface

Technologies Used

Python 3
Jupyter Notebook
Anaconda AI

 Development Environment

This project was developed and tested using Jupyter Notebook with assistance from Anaconda AI for coding support and learning.

 How to Run

1. Open the project in Jupyter Notebook.
2. Run all cells sequentially.
3. Follow the prompts to play the game.

Alternatively, if saved as a Python file:

bash
hangman.ipnb

Learning Outcomes

Python fundamentals
Conditional statements
Loops and iterations
String manipulation
Problem-solving and game logic
User input handling
